## 🏛️ FAST Financial Modeling Standard Compliance
Every workbook in this repository strictly adheres to the international **FAST Standard**:
- **F**lexible: Designed to accommodate restructuring and variable debt facilities.
- **A**ppropriate: Eliminates over-complex nested IF statements.
- **S**tructured: Strict visual separation of Inputs (Blue), Calculations (Black), and Outputs (Bold Green).
- **T**ransparent: One calculation per row, auditable by any institutional LP or auditor.
